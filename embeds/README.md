# Panoee iframe embed snippets

These files preserve the iframe and device-motion scripts supplied for the two Panoee tours. They are reference snippets for a website administrator; test them on the intended website before production.

- `campus-embed.html` — SKUAST-K outdoor campus tour
- `caiml-embed.html` — CAIML Discovery Building tour

The iframe height is set to 400px. Adjust its height and responsive styling for the target website. Device-motion behavior may require a secure context and browser permission. Do not paste the complete HTML document into a CMS field that accepts only iframe markup; use the CMS's supported embedding method.
